# 데이터로 읽는 소비자 마음: 쇼핑몰 구매 전환 예측

쇼핑몰에 방문한 사람이 구매까지 이어질지, 방문 기록에서 단서를 찾아봤습니다. 상품 페이지를 얼마나 살펴봤는지, 얼마나 머물렀는지, 어떤 환경에서 접속했는지를 이용해 **구매 여부**를 예측했습니다.

이번 데이터는 **방문이 끝난 뒤 정리된 기록**입니다. 따라서 결과는 과거 방문의 구매 여부를 구분한 성능으로 읽어 주세요. 방문 도중 구매를 예측하는 서비스에 쓰려면, 그 시점에 알 수 있었던 정보만으로 다시 평가해야 합니다. 거래 가치에서 계산되는 `PageValues`는 입력에서 제외했습니다.

## 결과부터 살펴보면

실제 구매 고객을 찾아낸 비율은 67.28%였습니다. 대신 구매할 것으로 예측한 고객 중 실제 구매자는 31.69%였습니다. 구매 고객을 더 찾는 쪽으로 판단 기준을 낮췄지만, 잘못 예측하는 경우도 많았습니다. 캠페인에 쓰려면 이 절충이 비용 면에서 괜찮은지 더 확인해야 합니다.

검증 자료에서 고른 모델은 **랜덤 포레스트**, 최종 판단에 쓴 임계값은 **0.20**입니다. 임계값은 예측 확률이 얼마 이상일 때 구매로 판단할지를 정하는 기준입니다.

| 정확도 | 정밀도 | 재현율 | F1 | AP |
| --- | --- | --- | --- | --- |
| 72.18% | 31.69% | 67.28% | 0.4308 | 0.3723 |

## 이 과정에서 다룬 내용

체류 시간 같은 수치형 데이터와 방문 월·방문자 유형 같은 범주형 데이터를 나눠 전처리했습니다. 범주는 원핫 인코딩으로 바꾸고, 로지스틱 회귀·의사결정나무·랜덤 포레스트를 비교했습니다. 나무 깊이를 바꾸며 과적합을 확인하고, 어떤 입력 항목에 모델이 많이 의존하는지도 살펴봤습니다.

학습·검증·테스트 자료는 따로 나눴습니다. 학습 자료로 모델을 만들고 검증 자료로 모델과 임계값을 고른 뒤, 테스트 자료는 마지막 확인에만 사용했습니다. 일반 사례가 많다는 점을 고려해, 모델을 고를 때는 정확도 대신 AP를 기준으로 삼았습니다.

## 내 데이터로 예측해 보기

Python **3.12**를 기준으로 실행했습니다. 먼저 이 저장소를 내려받고, 파일이 들어 있는 폴더에서 가상환경을 만들어 주세요.

```bash
python -m venv .venv
```

Windows PowerShell에서는 다음 명령으로 가상환경을 켭니다.

```powershell
.venv\Scripts\Activate.ps1
```

macOS나 Linux에서는 `source .venv/bin/activate`를 실행하면 됩니다. 필요한 패키지를 설치한 뒤 예제 입력으로 예측해 보세요.

```bash
python -m pip install -r requirements.txt
python predict.py --input sample_input.json
```

`sample_input.json`을 복사해서 방문 기록 값을 바꾸면 다른 입력도 시험해 볼 수 있습니다. 학습한 모델이 `model.joblib`에 들어 있어서 **예측만 할 때는 데이터를 다시 내려받지 않아도 됩니다.** 입력 항목 이름은 예제와 같아야 합니다. 빠진 항목이나 잘못된 숫자가 있으면 어떤 부분을 고쳐야 하는지 안내합니다.

출력의 `label`은 예측 결과이고, `positive_probability`는 구매일 것으로 모델이 계산한 확률입니다. `outside_training_range`에는 학습 때 보았던 수치 범위를 벗어난 항목이 표시됩니다. 확률은 별도로 보정하지 않은 값이므로 확정적인 판단으로 받아들이지는 마세요.

## 처음부터 다시 학습해 보기

```bash

```

재학습할 때는 공식 UCI 사이트에서 데이터를 받기 때문에 인터넷 연결이 필요합니다. 보고서·차트·모델 파일도 함께 다시 만듭니다. 노트북으로 따라가려면 `python -m pip install notebook ipykernel`을 추가로 실행해 주세요.

그래프를 새로 그릴 때는 맑은 고딕, AppleGothic, 나눔고딕 또는 Noto Sans CJK KR 중 설치된 글꼴을 사용합니다. 글자가 네모로 보인다면 한글 글꼴을 설치한 뒤 다시 실행해 주세요. 저장소에 올린 그래프는 한글 글꼴로 생성했습니다.
